# Output formats

The skill writes a canonical **Markdown report** at `tasks/research/<slug>.md` every run. When the user asks for additional formats (via the step 4 batched question), the skill chains downstream skills to generate those alongside the Markdown.

Format choice is captured once at step 4 and applied in step 8 (Decide & document).

## Available formats

### 1. Markdown report (default — always generated)

- Path: `tasks/research/<slug>.md`
- Generated directly by step 8 from `references/report-template.md`
- Canonical source of truth; all other formats derive from this
- No extra tool calls; no extra cost

### 2. Executive deck (.pptx)

- Path: `tasks/research/<slug>.pptx`
- Generated by chaining to `anthropic-skills:pptx`
- **When to use**: stakeholder meetings, executive briefings, board reviews
- **Slide structure (8–12 slides)**:
  1. Title — product name + decision verdict + date
  2. Context — what we were researching and why (1–2 sentences from "Context")
  3. Requirements snapshot — must-have / nice-to-have / dealbreaker summary
  4. Candidate slate — single-slide table with 3 candidates
  5. Compliance + compatibility — pass/fail per candidate
  6. Price discovery — fair-price band table + best channel
  7. Decision matrix — weighted-score chart (or AHP/Pugh visualization)
  8. TCO comparison — bar/column chart of net TCO per candidate
  9. Risk summary — top-3 FMEA-lite items + vendor risk one-liner
  10. Recommendation — primary pick + target price + runner-up + do-not-buy
  11. Pre-mortem + lifecycle — top regret scenarios + key dated checklist items
  12. Sources — numbered citation list (split across slides if needed)

### 3. Polished PDF brief

- Path: `tasks/research/<slug>.pdf`
- Generated by chaining to `anthropic-skills:pdf`
- **When to use**: archival, email-attachable single-file deliverable, print-ready
- **Structure**: full Markdown report rendered as PDF with:
  - Cover header (product + date + audience + Kraljic class)
  - Numbered sections matching Markdown
  - Page numbers in footer
  - Clickable hyperlinks for sources
  - Embedded charts where the Markdown has tables (TCO, decision matrix)

### 4. Stakeholder one-pager

- Path: `tasks/research/<slug>-one-pager.md` (always) + `tasks/research/<slug>-one-pager.pdf` (if user asked for PDF version)
- **When to use**: bring-to-meeting, exec quick-read, customer-facing decision summary
- **Strict 1-page constraint** — content must fit single A4/Letter page; condensed sections only:
  - Verdict (1 sentence)
  - Target price + best channel (1 line)
  - Top 3 reasons why (3 bullets, 1 line each)
  - Top 3 risks + mitigations (3 lines)
  - Walk-away price (1 line)
  - Next step / dated action (1 line)
  - Compact sources block (3–5 inline links)
- See "One-pager template" section at the bottom of `references/report-template.md` for the exact skeleton

### 5. Word .docx report

- Path: `tasks/research/<slug>.docx`
- Generated by chaining to `anthropic-skills:docx`
- **When to use**: procurement team review, legal redlining, contract attachment, corporate-style internal distribution
- **Structure**: full Markdown report converted, preserving:
  - Section numbering
  - Tables (formatted as Word tables, not images)
  - Source links as Word hyperlinks
  - Headings styled per default Word heading hierarchy

## Format chain — how step 8 dispatches

After writing the canonical Markdown:

1. Check the user's format selections captured at step 4.
2. For each non-default format selected, invoke the corresponding chain:
   - `.pptx` → call `anthropic-skills:pptx` with the slide outline above, sourcing data from the Markdown
   - `.pdf` → call `anthropic-skills:pdf` with the Markdown source
   - One-pager `.md` → write the condensed template directly; if `.pdf` of one-pager requested, then also chain `anthropic-skills:pdf` on the one-pager .md
   - `.docx` → call `anthropic-skills:docx` with the Markdown source
3. Confirm all paths back to the user as a single bulleted output.

If a chained skill fails (e.g., `anthropic-skills:pptx` errors), surface the failure to the user — do NOT silently skip — and offer to retry or fall back to Markdown-only.

## Cost vs benefit

| Format | Generation cost (relative) | Best use case |
|---|---|---|
| Markdown | 1× (baseline) | Always — canonical |
| One-pager .md | ~1.1× | Meetings, quick-share |
| One-pager PDF | ~1.3× | Bring-to-meeting print |
| PDF brief | ~1.4× | Archive, email |
| Word .docx | ~1.4× | Procurement / legal review |
| Executive deck .pptx | ~1.8× | Stakeholder presentation |

The Markdown is always the source of truth — if other formats drift (rare, but possible from format-specific conversion), trust the Markdown.

## Non-goals

- The skill does not generate charts beyond what the chained skills (`pptx`, `pdf`) natively support — no custom matplotlib output.
- The skill does not generate animated / interactive content.
- The skill does not auto-upload to Google Slides / SharePoint / cloud — output is filesystem only.
