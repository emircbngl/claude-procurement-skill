# Domain: Camera (mirrorless, DSLR, lenses, supporting gear)

## Research dimensions
- **functional_specs**: sensor format (full-frame / APS-C / Micro 4/3 / 1"), megapixels, AF system (PDAF + cross points + subject detection), video specs (4K/8K, codec, bitrate, internal vs external), IBIS stops, viewfinder (EVF res, lag), burst rate, buffer, weather sealing, weight
- **quality_signals**: DXOMark sensor scores, DPReview legacy archives, PetaPixel, professional reviews (photographers actually using for paid work)
- **economic**: body + 2–4 lens kit cost (most cost is in glass, not body), batteries (2–3 spare for serious use), memory cards (matched to write spec), filters (UV/CPL/ND), bags, expected resale value (cameras depreciate ~20–30% in 2yr, lenses hold value much better)
- **usage_fit**: portrait / landscape / wildlife / sports / street / video / wedding (pro) / travel / casual family

## Required user inputs (overrides universal)
- Existing lens collection (HUGE — switching mounts means losing investment)
- Primary genre (drives lens kit + AF system priority)
- Photo-vs-video split (some bodies optimize one over the other)
- Carry tolerance (full-frame + pro lenses = 2–4kg; APS-C = 0.5–1.5kg)
- Tier (entry / enthusiast / prosumer / pro)
- Region (TR import duties on cameras: high; gray-market via Hong Kong cheap but voids warranty)

## Standards & compatibility axes

| Axis | Values | Compat rule |
|------|--------|-------------|
| **Lens mount** | Canon RF / EF / EF-M / EF-S; Nikon Z / F; Sony E (FE FF + E APS-C); Fujifilm X / G (medium format); MFT (Panasonic/OM); Leica M / L | Lens mount must physically match body; native is best; adapters EF→RF, F→Z work (sometimes with feature loss) |
| **Sensor format** | Full-frame / APS-C / MFT / 1"  | Lens marked for smaller format works only on that or smaller; full-frame lens on crop body = no waste but crops field of view |
| **Memory card** | SD UHS-I, SD UHS-II, CFexpress Type A (Sony), CFexpress Type B (Canon, Nikon, Fuji), microSD (action cams) | Body slot determines card; higher tier cards needed for 4K/8K video write spec |
| **Battery** | proprietary (LP-E6/LP-E6NH for Canon R bodies; NP-FZ100 for Sony A7/A9; EN-EL15c for Nikon Z) | Cross-generation often compatible within brand; third-party (Wasabi Power) usually fine for stills, may not work with some advanced features |
| **Hot shoe** | ISO 518 standard (universal) + brand-specific data pins (TTL flash sync only with brand or Profoto/Godox brand-specific) | TTL requires brand-matched or licensed third-party flash |
| **Tripod thread** | 1/4"-20 (standard) and 3/8"-16 (heavier mounts) | All bodies support 1/4"; larger via adapter |
| **L-bracket** | Arca-Swiss standard | Buy Arca-Swiss compatible plate + brand-specific L-bracket; matches industry tripod heads |
| **Strap mount** | Standard eyelet / Peak Design anchor / Black Rapid | Multi-eyelet bodies allow modular system |
| **External recording** | HDMI clean output, USB-C UVC | Atomos / external recorder requires clean HDMI; check body spec |
| **Mic input** | 3.5mm TRS (most), XLR (cinema bodies + accessory shoe interfaces) | Audio quality jump from XLR via brand XLR handle |

## Common pitfalls

- **Mount switching cost** — moving from Canon EF to Sony E means selling all lenses (with depreciation) and rebuying. Adapters work but with caveats.
- **Adapter feature loss** — EF→RF adapter mostly works; EF→Z mostly works; older third-party EF lenses sometimes fail AF on R/Z bodies.
- **APS-C lens on full-frame body** — works but auto-crops (uses center). Wastes resolution.
- **SD card write spec too low for 4K/8K** — video drops frames; use UHS-II V60/V90 or CFexpress per body spec.
- **Counterfeit memory cards** — SanDisk Extreme Pro is heavily counterfeited on marketplaces. Buy from authorized only.
- **Gray-market camera bodies** — Canon/Nikon/Sony don't honor international warranty for gray imports in many regions including TR.
- **Battery counterfeits** — third-party-marketplace "Sony NP-FZ100" / "Canon LP-E6NH" / similar OEM-branded batteries are heavily counterfeited globally and may overheat; stick to reputable third-party (Wasabi Power, Watson, SmallRig) or genuine OEM from authorized seller.
- **Lens-body firmware mismatch** — newer lens on older body may need body firmware update for AF; check before assuming compatibility.
- **Hot shoe pin damage** — non-brand flashes can short pins on certain bodies (older Canon shoes especially). Use brand-licensed or known-safe third-party.
- **IBIS + OIS conflict** — some Sony bodies disable lens OIS when IBIS active; some Canon bodies require specific firmware; check per combo.

## Used market specifics

- Cameras depreciate 20–30% in 2yr; lenses hold value much better (often <10% in 2yr for premium glass).
- Shutter count (DSLR) is a reliability proxy — ~150–300k expected before service. Mirrorless EVF/sensor wear less time-bound but check eyecup, screen, port wear.
- Trustworthy specialty resellers: MPB, KEH, Adorama Used, B&H Used. eBay sold listings for price reference; private sale via local photo forums for best price.

## Regional notes

- **Authorized distributor essential** — Canon / Nikon / Sony / Fujifilm / Panasonic enforce regional warranty; verify the brand's authorized distributor in the user's country before quoting.
- **Gray-market sources** (HK, Dubai, certain EU resellers shipping globally) often 20–35% cheaper but void manufacturer warranty in destination region. Worth it only if user accepts self-funded service or has separate insurance.
- **Specialty resellers** — verify authorized status in user's region; local pro shops are common in major cities, listed via brand's official dealer page.
- **Professional service membership** (Canon CPS, Nikon NPS, Sony Imaging Pro Support) is region-specific and tied to body serial registration.

## B2B variant (studio / agency / production)
- Bulk lens rentals through brand B2B programs (Canon Professional Services, Sony Pro)
- Service-level membership (CPS / NPS / SPS) for fast repair and loaner gear
- Multi-body kit (matched bodies + lens overlap for redundancy on paid jobs)
- Studio strobes (Profoto, Broncolor, Godox) — XLR/sync cable standards
